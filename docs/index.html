Relatude.DB — the super toolkit for AI agents

An open-source, object-oriented graph database for .NET where your C# classes are the schema — no SQL, no migrations, no ORM layer. Search, facets, geo, files and an admin UI are built into the engine, and it runs in-process, so a query is just a method call.

That makes it a perfect match for AI agents. Assembling the same capabilities from scratch across separate systems is a mess — here they are safe, powerful building blocks your AI can use directly, while the code it writes stays small, readable and fully under your control.
