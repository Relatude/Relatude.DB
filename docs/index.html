Relatude.DB — the super toolkit for AI agents

Relatude.DB is an open-source, object-oriented graph database for .NET where your C# classes are the schema — no SQL, no migrations, no ORM mapping layer. Full-text (BM25) search, vector/semantic search, facets, geo queries, file storage and an admin UI are part of the engine, and it runs in-process, so a query is just a method call. That makes it a compact toolkit for AI agents and the apps around them: everything an agent needs to store, search and reason over is one dependency away.

Introduction → A short, practical getting-started: model, setup, query and write in a few minutes. Manual → Data modelling and querying in depth, built around one running example domain. Agent skill ↓ relatude-db.skill — the same knowledge packaged for AI coding agents. NuGet → Relatude.DB.Server — add one package to an ASP.NET Core app and you are running. GitHub repository → Source, examples, benchmarks and issues at github.com/Relatude/Relatude.DB. relatude.com → The company behind Relatude.DB.
